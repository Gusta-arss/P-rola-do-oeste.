# Portal do Aluno — redesign demonstrativo

Protótipo front-end responsivo inspirado na paleta amarelo e azul associada à Pérola do Oeste, com uma interface mais atual para apresentar informações de EduCard e VEM Escolar.

## Como abrir
1. Extraia o arquivo ZIP.
2. Abra `index.html` em um navegador atualizado.
3. Para editar, abra a pasta no VS Code ou editor semelhante.

Não exige instalação de dependências nem servidor para a demonstração. A fonte DM Sans/Manrope usa Google Fonts quando há conexão; se estiver offline, serão usadas fontes de sistema.

## Interações incluídas
- Menu responsivo e navegação pelas seções.
- Botões para alternar o checklist EduCard/VEM Escolar.
- Marcação dos documentos conferidos com barra de progresso.
- Botão para limpar as marcações.
- Botão para copiar a chave Pix informada no material de referência.
- Dúvidas frequentes expansíveis e atalho para o telefone.

## Importante
Este é um protótipo independente, não oficial. Não possui login, envio de documentos, criação de processos, consulta de status, integração de pagamentos nem conexão com sistemas da empresa. As taxas, dados bancários, links e procedimentos devem ser confirmados nos canais oficiais antes de qualquer publicação. A marca e a identidade visual devem ser usadas com autorização quando aplicável.
